# Learning Cards

Four layers per card: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Gap evidence follows each cluster.

---

## c25 修复伴随件（3 件）— 证据：php2shell 系列把「漏洞+检测规则」成对发布；BeautifulRust：移植必须先搬测试

- **L91 检测件伴随**：L0 修好一个 bug，必须同时交"下次怎么提前发现它"的哨兵。只修不设哨，等于等着它再犯。L1 校验修复产物包含配套检测件（断言/规则/监控项），缺失 → 修复不算完成。L2 断言=①无检测件判未完成、②有检测件放行。
- **L92 移植等价性**：L0 把代码搬到新地方，先搬老测试：老测试全过，才叫"搬好了"，不叫"重写了一份像的"。L1 移植前校验测试套件已迁移且通过率达标，未达标判「移植未完成」。L2 断言=①测试未迁移拦截、②迁移且通过放行。
- **L93 跨实现等价**：L0 同一个功能有两份实现时，拿同样的输入喂两份，答案必须一致；不一致就说明有一份是错的。L1 固定输入集跑双实现，diff 输出，不一致定位首个分歧点。L2 断言=①分歧点被定位、②一致判 PASS。
